# Swiggy-sales-analysis-dashboard
Swiggy Sales Data Analysis using PostgreSQL and Power BI | SQL queries, revenue analysis, restaurant performance, and business insights.

How to Use
PostgreSQL
1. Install PostgreSQL and open a SQL client such as pgAdmin.
2. Create a database for the project.
3. Import the Swiggy dataset into a table named swiggy.
4. Open Swiggy_query.sql in your SQL editor.
5. Run the queries to explore the data and reproduce the analyses.
The SQL script expects the table to contain the columns referenced in the queries, including State, City, Dish Name, Price (INR), Restaurant Name, Rating, and Order Date. Check your imported column names and data types before running the queries.

Power BI
1. Make sure the complete Power BI Project folders are present in the repository.
2. Open Swiggy_Sales.pbip in Power BI Desktop.
3. Configure or update the data source connection if prompted.
4. Refresh the data to load the latest dataset.
